## 🧠 Sobre o projeto

Este projeto consiste em um **jogo simples desenvolvido para navegador**, utilizando **HTML, CSS e JavaScript**.

A aplicação foi criada com o objetivo de praticar conceitos fundamentais de programação, como **lógica de jogo**, **controle de estados** e **interação com o usuário**. O jogo roda diretamente no navegador, sem necessidade de instalação ou backend, sendo totalmente focado no front-end.

A estrutura do projeto é composta por arquivos básicos da web:
- `index.html`, responsável pela estrutura da interface  
- `style.css`, que define o visual do jogo  
- `script.js`, onde está implementada toda a lógica e funcionamento  

## 🎮 Funcionalidade

O projeto apresenta uma mecânica simples de jogo, onde o usuário interage com elementos na tela seguindo regras definidas pela lógica em JavaScript. Esse tipo de aplicação é comum em projetos iniciais de jogos web, como jogos de dados ou interação por turnos :contentReference[oaicite:0]{index=0}.

## 🎯 Objetivo

O principal objetivo foi **aprimorar habilidades em JavaScript**, especialmente na manipulação do DOM, eventos e criação de comportamentos dinâmicos dentro de um jogo.

## 💡 Considerações

Este é um projeto desenvolvido com foco em aprendizado, mas que serve como base para a criação de jogos mais complexos e aplicações interativas na web.
